# Wiring Verification

Trace trigger → registration → dispatcher → implementation → observable result through the path actually installed.

For a hook inspect selected profile, installed settings command, event matcher and bundled `.mjs`. Send realistic stdin in temporary HOME/project state; check exit status, protocol and effect. A source import misses stale bundles, missing registrations and ESM failures.

For a CLI test the declared bin from packed/installed layout. For API or UI work exercise the public route with representative data and inspect response or state. Use local fixtures and authorized environments.

Check missing optional dependencies and unsupported input. Distinguish an intentional no-op from a swallowed failure. Verify modules are reachable and generated outputs are current.

Report entry point, call path, fixture or command and observed result. Do not assume unrelated orchestration scripts exist.
